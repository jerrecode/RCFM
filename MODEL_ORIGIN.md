## Statement of Origin

The Radial-Cyclic Field Model (RCFM) is a cosmological model originally
conceived and developed by Jeremy Erich Resch.

computational implementations of the model were created by the author
and first documented in this repository.

This repository therefore represents the primary development record
for the model.

## Scope of the Model

The Radial-Cyclic Field Model proposes a cosmological framework in which
the evolution of spacetime is described through radial cyclic dynamics.

The repository contains:

- the scientific manuscript describing the model
- simulation code used to generate figures
- computational visualizations
- versioned snapshots of the manuscript
- supporting documentation

These materials collectively document the theoretical and computational
development of the model.

## Intellectual Context

The Radial-Cyclic Field Model was developed as an independent
cosmological framework exploring cyclic radial dynamics of spacetime.

It draws conceptual inspiration from existing research areas including:

• cyclic cosmologies
• modified gravity theories
• non-standard spacetime geometries

but constitutes an original theoretical formulation.
